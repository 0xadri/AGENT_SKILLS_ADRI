# Readme For Humans

This guide is for humans only, to help you dear human being.

# Why Use This Skill?

Manually copying an answer breaks the markdown format.

Copy to clipboard the last answer with clean markdown format.

## Note

Uses `pbcopy`. macOS only.

# FAQ: Response As Markdown Skill

## When?

Want last output elsewhere. Docs, ticket, chat. No manual reformat.

## What?

Formats last meaningful block as clean markdown. Copies to clipboard.

## Will it do any code change?

No. Never. Clipboard only.

## Example Prompt

```markdown
/get-response-as-markdown
```
