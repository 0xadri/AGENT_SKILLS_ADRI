# SDD Jazz

SDD Jazz is a SDD framework. SDD as Specs Driven Development.

SDD Jazz has an opinionated behavior over configurability.

Think:

- tiny library that get the job done over fancy do-it-all framework
- low tech that actually works

# FAQ

- Why are the skills numbers `sddj-0-*`, `sddj-1-*`, and so on? -> Because that's the typical order in which you run them
