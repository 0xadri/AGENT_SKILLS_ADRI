# What's SDD aka Spec Driven Development?

- The essence of SDD = an advanced plan mode
- SDD is probably what you kind of already do: create plan → review plan → implement plan → review implementation

# Typical Dev Journey

From `Plan Mode` to `SDD`:

1. You use plan mode in your context window
2. You use plan mode and write the output to md files
3. You use SDD frameworks
4. You use SDD frameworks you modified/built

In the end you use any of the above strategies depending the task size and complexity.

# Use Cases

Problems Addressed:

- the LLM is overwhelmed, plan reaches the limit of a single context window
- the Human is overwhelmed, plan reaches the limit of user's understanding and control
- plan mode frustrates you for larger tasks, too unpredictable and inconsistent
- writing outcome of plan mode to `md` files is not good enough
